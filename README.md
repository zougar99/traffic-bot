# 🖥 traffic-bot

> 🚦 Desktop traffic lab — Selenium Chrome sessions, proxy rotation, search modes, Telegram alerts. Built with Electron.

---

## ✨ Features

- ✔ **Traffic automation laboratory**
- ✔ **Selenium Chrome with proxy rotation**
- ✔ **Telegram alerts and search modes**
- ✔ Lightweight and optimized
- ✔ Cross-platform compatibility
- ✔ Regular updates

---

## 💻 Tech Stack

| Component | Technology |
|-----------|-----------|
| Language | Python |
| UI | CustomTkinter / PyQt |
| Platform | Windows / Linux / macOS |

---

## 🚀 Installation

```bash
git clone https://github.com/zougar99/traffic-bot.git
cd traffic-bot
pip install -r requirements.txt
```

---

## 🧰 Usage

```bash
python main.py
```
